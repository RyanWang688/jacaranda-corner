# Jacaranda Corner · 悉尼蓝花楹街角

用 Three.js 制作的可交互微缩场景：奶油白三层转角老楼、环绕铁艺阳台、紫色长椅，被六棵蓝花楹围合。

- 拖拽旋转，滚轮 / 双指缩放
- 白天、黄昏、夜晚三个时段平滑切换；夜间窗户与路灯发出暖光
- 三渲二明暗、树梢轻摆、花瓣飘落
- 程序化生成的枝干与约 5 万片实例化花片

## 运行

全部源码都在 `index.html` 里，没有构建步骤。three.js 与字体从 CDN 加载，需要联网。

用任意静态服务器打开即可，例如：

```bash
python -m http.server 8630
```

然后访问 http://localhost:8630/ 。
